# Et toi ? — production orale sans noms écrits

Règle commune à toutes les activités Et toi de l’unité nourriture : les élèves produisent les phrases et retrouvent le vocabulaire de mémoire à partir des illustrations. Aucun nom d’aliment ou de boisson n’est affiché dans les choix, la récapitulation, les messages ou les commandes des amis au café. La phrase modèle Je voudrais est également masquée. Les questions de lancement, les consignes pratiques, les boutons et les nombres restent visibles.

Le composant commun impose hideNames pour éviter un oubli dans une nouvelle activité. Les descriptions accessibles non visuelles sont conservées. Au café, une image remplace le nom de la boisson choisie sous chaque ami.

Activités concernées : pique-nique en famille, marché, café, cantine, À table et Je compose ma salade. La numérotation reste 3 pour les cinq premières concernées hors À table, et 4 pour À table. Les autres modes de découverte et de compréhension gardent leurs supports écrits.

Vérification dans le navigateur des six jeux : noms invisibles dans les choix et les récapitulatifs ; phrase modèle masquée ; choix puis nouvel élève avec remise à zéro. Au marché, trois clics produisent une quantité de trois. Au café, trois choix donnent trois boissons illustrées sous les amis et sur la table, sans noms écrits. Capture : et-toi-sans-noms.jpg.
